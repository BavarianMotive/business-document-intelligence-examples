# Local Sample Documents

Place **redacted or synthetic** PDF/JPEG/PNG/WebP test documents in this directory when running examples locally.

Files in `samples/` are ignored by Git so real invoices, receipts, and other business documents are not accidentally committed.

Recommended local names:

```text
samples/invoice.pdf
samples/receipt.png
samples/document.jpg
```

Do not commit customer documents, payment-card data, credentials, API keys, or other sensitive business information.
